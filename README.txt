----------
Upload the contents of this folder to your hosting public web directory
(or upload this ZIP if your hosting panel supports ZIP extraction).

The website is a static HTML/CSS/JavaScript site, so no Node.js, database,
or backend server is required for deployment.

IMPORTANT
---------
Keep the assets/ folder in the same location as index.html.
Do not rename or move files inside assets/ after deployment unless the
matching references in index.html are also changed.
